# Wholesale Revenue Analysis

## Project Overview

This SQL project analyzes wholesale sales data for a motorcycle parts company.

The goal was to calculate net revenue by product line and compare performance across warehouses and months.

## Business Task

Calculate net revenue for wholesale orders and group results by:

- Product line
- Month
- Warehouse

## SQL Skills Used

- Filtering with WHERE
- Aggregation with SUM()
- GROUP BY
- Date formatting using TO_CHAR()
- Sorting results with ORDER BY

## Key Output

The final report provides net revenue by product line, month, and warehouse for wholesale customers only.
